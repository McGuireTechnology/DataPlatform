# Getting Started

Use this section to help new contributors understand how to work with the Data Platform.

## Local Documentation

Install dependencies:

```sh
npm install
```

Start the documentation site:

```sh
npm run docs:dev
```

Build the static site:

```sh
npm run docs:build
```

Preview the production build:

```sh
npm run docs:preview
```
